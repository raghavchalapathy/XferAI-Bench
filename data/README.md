# data/

`complete_data/`, `sample_data/` and `synthetic_data/` each have `input/`, `output/` and `metadata/`. Their contents are gitignored; only README and .gitkeep files are tracked. **Never commit complete or real data**, or any data you do not have the rights to. Synthetic data is regenerated by `xferbench synth generate` / `scripts/data_prep.sh` (generator code: `src/xferbench/synth/`).
