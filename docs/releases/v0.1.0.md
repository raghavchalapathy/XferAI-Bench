First public release of XferAI-Bench (`xfer-bench`), a local, offline benchmark for cold item-location pairs:
an existing retail item launching at a Forecast Pixel Group (FPG) where that pair has never sold, with 52 weekly
unit forecasts and PAIR0-E / PAIR0-N always scored separately.

> **Rankings are pending.** No rights-cleared real benchmark has been run. The bundled data is **synthetic and
> only tests the software**; results on it say nothing about which method is better. No method is claimed to
> forecast well from day zero.

## Highlights
- Baselines B0-B3, business rules M1/M2, M3 (needs your recipe), M4.lightgbm (optional extra).
- Experimental, licence-pinned donor-prior adapters (Chronos-2, Chronos-Bolt, TimesFM 2.5, DeepAR count), tested
  with fake backends only.
- Shared retail hierarchy (item -> subcategory -> product type; category -> product type).
- Leakage-safe origin contexts, chronological splits, validation-only selection, local HTML report.
- Your own data stays local: LOCAL DATA banner, salted IDs, gitignored outputs, no telemetry.
- New: [docs/GETTING_STARTED.md](https://github.com/raghavchalapathy/XferAI-Bench/blob/main/docs/GETTING_STARTED.md) and
  [docs/DIY-GettingStarted.md](https://github.com/raghavchalapathy/XferAI-Bench/blob/main/docs/DIY-GettingStarted.md) for coding assistants.

## Install
Not on PyPI. Python 3.11+:

```bash
git clone --branch v0.1.0 https://github.com/raghavchalapathy/XferAI-Bench.git && cd XferAI-Bench
python3 -m venv .venv && .venv/bin/python -m pip install -e .
.venv/bin/xferbench demo --out ./xb-demo
```

CI is green on ubuntu, macOS and Windows with Python 3.11 and 3.13.
