Getting started

Run XferAI-Bench on your laptop, offline and free.

  1. InstallGit and Python 3.11+; Linux, macOS or Windows. No GPU, no paid services.
    git clone https://github.com/raghavchalapathy/XferAI-Bench.git
cd XferAI-Bench
bash xferAI_setup.sh
    Windows PowerShell: powershell -ExecutionPolicy Bypass -File .\xferAI_setup.ps1. bash xferAI_setup.sh --help lists the flags.
  2. Run the demo experiment
    uv run xferbench experiment run exp01_synthetic_lightgbm_analogs
    Without uv: .venv/bin/xferbench. Open SUMMARY.md, leaderboard.html and report.html in eval/exp01_synthetic_lightgbm_analogs__synthetic/.
  3. Add your dataPut CSV or Parquet files in data/sample_data/input/ (git-ignored), then describe and validate them:
    uv run xferbench metadata wizard --data data/sample_data/input --out data/sample_data/metadata/metadata.json
uv run xferbench validate --metadata data/sample_data/metadata/metadata.json
  4. Run your experiment
    uv run xferbench experiment new exp04_mydata_lightgbm --from exp01_synthetic_lightgbm_analogs
uv run xferbench experiment run exp04_mydata_lightgbm --tier sample
    First point experiments/exp04_mydata_lightgbm/configs/sample.yaml at your metadata.json. Data stays local.
  5. Use an LLMHand GETTING_STARTED.md to your coding assistant.
