Get started with XferAI-Bench

Test forecasting methods for one hard case: an existing item launching where it has never sold. The benchmark runs on your own laptop, offline and free.

Status: scored rankings are pending. Built-in data is synthetic, so it checks the software works, not which method wins on real data.

You need

Python 3.11+, Git, and a macOS or Linux shell.

Clone it and get a first report

git clone https://github.com/raghavchalapathy/XferAI-Bench.git
cd XferAI-Bench
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/xferbench demo --out xb-demo

Open xb-demo/report.html.

Use your own data

First activate the venv so xferbench is on your PATH: source .venv/bin/activate

  1. Copy the template: xferbench synth generate --preset tiny --out local/template, then cp -r local/template local/my-data
  2. In local/my-data, set dataset.synthetic to false, delete _synthetic_truth/ and generation_report.json, swap in your tables and edit metadata.json (details: full guide, step 6)
  3. validate → split → run --local-data → select → run --stage test → report

Keep your data in local/ and results in runs/local/; both are gitignored. The benchmark runs offline: network and service calls stay off.

Full guide: docs/GETTING_STARTED.md DIY Getting Started: docs/DIY-GettingStarted.md

Reading results

PAIR0-E (established location) and PAIR0-N (new location) are always shown separately. Lower WMAPE is better, and Bias shows over- or under-forecasting. Results on your own data are marked LOCAL DATA and are not leaderboard results.
