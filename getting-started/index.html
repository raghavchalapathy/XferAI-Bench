Getting started

Run XferAI-Bench on your laptop, offline and free.

  1. InstallPython 3.11+, Git, macOS or Linux.
  2. Clone & demo
    git clone https://github.com/raghavchalapathy/XferAI-Bench.git
cd XferAI-Bench
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/xferbench demo --out xb-demo
    Open xb-demo/report.html.
  3. Add your dataCopy the template into local/my-data, swap in your tables, edit metadata.json.
  4. Runvalidate → split → run → select → test → report. Data stays local.
  5. Use an LLMHand DIY-GettingStarted.md to your coding assistant.

Open the repo ↗

Built-in data is synthetic; it checks the software, not which method wins.
